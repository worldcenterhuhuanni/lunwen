# 优化论文阅读界面

## Why

侧栏粘贴文字输入长期占据纵向空间，模型结果只能在窄栏中阅读；现有 MarkdownLite 语法与排版能力也不足以承载专业模板输出。

## What

- 将粘贴文字改为默认折叠的轻量入口
- 每条完整解读右上角提供放大阅读操作
- 新增沉浸式 Markdown 弹框，使用 `@ant-design/x-markdown` 完整渲染流式输出
- 按“文人书房”方向统一侧栏色彩、层级、留白与交互状态

## Not

- 不引入远程字体或整套 UI 框架
- 不改变论文提取、模型调用和模板选择逻辑

## 验收

1. 默认状态下粘贴文字区域仅占一行，展开后仍可正常提交
2. 已生成的助手 Markdown 右上角出现放大按钮
3. 弹框支持关闭、Escape、滚动和窄屏适配
4. 标题、列表、引用、代码、链接、分隔线等常用 Markdown 正确展示
5. 明暗主题下均有清晰对比度和键盘焦点
