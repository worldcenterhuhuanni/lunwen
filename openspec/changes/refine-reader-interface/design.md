# Design: Literati Reading Room

## 视觉方向

- 燕麦宣纸底色 `#F1E8D8`
- 象牙阅读页 `#FBF6EA`
- 胡桃木正文 `#342B22`
- 栗壳操作色 `#6F4E37`
- 灰褐辅助文字 `#766B5D`
- 亚麻分隔线 `#D9CCB8`
- 暗朱砂批注色 `#9A4938`
- 旧金强调色 `#B08A55`

整体采用低饱和、同温区的米黄与木色，不使用青色或紫色。标题使用宋体建立书卷气，正文用系统无衬线保证窄屏可读性，元信息使用等宽字体形成藏书签感。签名元素是结果卡片旁的暗朱砂眉批与极细旧金压线；高光只出现在关键动作和纸张边缘，避免把暖米色做成常见的“奶油色模板”。

## 交互

粘贴文字以折叠面板呈现，默认只显示名称与说明；有草稿时显示字符数并保留展开状态。

每条非空助手结果有独立放大按钮。弹框使用固定遮罩和文档纸张布局，点击遮罩、关闭按钮或 Escape 均可退出；打开后锁定在当前结果文本，不受后续流式更新影响。

## Markdown

使用 `@ant-design/x-markdown` 2.x 渲染模型的流式内容，获得 CommonMark/GFM、表格、任务列表和安全净化能力。通过局部 CSS 变量与组件样式覆盖形成书页排版，外链在新标签页打开。
