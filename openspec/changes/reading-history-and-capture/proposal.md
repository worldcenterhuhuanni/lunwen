# 解读历史、索引复用与划词入口

## Why

三个真实损耗，都不是功能缺失而是已有资产没被留住：

1. **解读结果活不过一次侧栏关闭。** 全部会话状态只存在 React state 里，切窗口或关侧栏即清零，用户要重新解读同一篇材料。
2. **索引建了却不能复用。** `saveWorkspace` 已经把工作区写进 IndexedDB，GitHub 的 `workspaceId` 甚至就是 `github:owner/repo:sha` 这种内容寻址，本地目录的 `rootHandle` 也已持久化；但界面上没有任何入口，同一个仓库分析两次要重新下载解压全量源码。旧索引同时永久堆积，没有删除手段。
3. **进入成本只有整页/粘贴两条路。** 用户看到网页里一段话想解读，必须手动复制再展开粘贴抽屉。

## What

- 解读会话（材料元信息 + 全部对话轮次）持久化到 IndexedDB，侧栏重开自动恢复最近一次会话
- 新增「最近材料」列表：可恢复历史会话、可复用已建索引、可删除单条（同时清理其文件行）
- GitHub 同 commit 重复导入直接命中已有索引，跳过下载与解压
- 本地工作区显示索引时间，并提供一键重新索引；已授权目录经权限确认后可直接重建
- 新增划词解读：选中网页文字 → 右键 → 打开侧栏并按当前模板解读
- 小体验修：追问框改多行输入（Enter 发送 / Shift+Enter 换行）、工具轨迹可展开查看参数与结果
- 配套重构：`App.tsx` 拆出 `useAnalysis` 状态机与三个模式面板

## Not

- 不做搜索性能优化（大仓库全量线性扫描保持现状）
- 不改模型通路、提示词模板与写回确认流程
- 不做跨设备同步，历史仅存本机 IndexedDB
- 不做本地文件变更的自动监听，重索引由用户触发

## 验收

1. 侧栏关闭重开后，最近一次解读的材料与全部对话轮次原样恢复
2. 「最近材料」可列出历史条目，点击恢复会话，删除后其索引文件一并从 IndexedDB 移除
3. 同一 GitHub 仓库同一 commit 二次导入不产生归档下载请求，直接进入分析
4. 本地工作区显示索引时间；点击重新索引后统计数字与时间戳更新
5. 选中网页文字右键解读，侧栏打开并对该段文字给出解读
6. 追问框 Shift+Enter 换行、Enter 发送；工具轨迹条目可展开看到参数与结果摘要
7. `pnpm test`、`pnpm compile` 通过，`openspec validate reading-history-and-capture --strict` 通过
