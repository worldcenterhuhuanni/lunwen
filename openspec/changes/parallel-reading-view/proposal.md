# 原文对照阅读

## Why

论文解读的核心动作是「读一句原文，看一句解释」，但现在两者永远不在同一屏：

- 侧栏只有解读，没有原文；想核对原文得切回标签页，来回跳
- 点放大按钮，未开独立大窗口时弹出的是侧栏内弹框，宽度仍是侧栏那么宽，读长篇解读依然憋屈
- 想就某段原文追问，只能自己手动复制粘贴，粘完还看不出这条回答当初问的是哪一段

结果是：解读越长越难用，追问越多越乱，回头翻自己问过什么完全靠记忆。

## What

新增全宽的原文对照视图：左边 PDF 原样排版，右边 AI 分析，同屏对照。

- 点放大按钮：未开启独立大窗口时打开新标签页全宽对照；开启时仍走独立窗口，同一个页面
- 左栏用 pdf.js 真实渲染，图表、公式、分栏保持原样，文字可选中
- 选中任意原文片段 → 浮出「问 AI」→ 只把这段原文和问题发给模型，不重传整篇 PDF
- 每条回答记住它引用的原文片段：点回答滚到原文并高亮，点原文高亮滚到对应回答
- 对照视图里的追问与侧栏共用同一条会话记录，历史里能看到完整往来

## Not

- 不做 AI 输出里的引用标记解析（要求模型吐 `[[p3:...]]` 这类标记，网页桥接下不可靠，解析失败整条链就断）；关联一律由用户的选中动作产生
- 不改论文首轮解读的既有流程与提示词模板
- 不做 PDF 批注、笔记导出、跨文档检索
- 不动 GitHub / 本地工作区两种模式
- HTML 材料本期只用纯文本左栏兜底，不做网页原样重排

## 验收

1. 未开启独立大窗口时点放大，打开新标签页并左右分栏，左侧 PDF 与原文件排版一致
2. 左栏可翻页浏览全文，文字可选中复制
3. 选中一段原文后可发起追问，请求体里只包含该片段而非整篇 PDF
4. 每条基于片段的回答显示其引用原文；点击可双向定位并高亮
5. 关掉对照标签页再从侧栏打开，之前的问答与片段高亮仍在
6. 侧栏「最近材料」里能看到对照视图中产生的追问
7. `pnpm test`、`pnpm compile`、`pnpm build` 通过
