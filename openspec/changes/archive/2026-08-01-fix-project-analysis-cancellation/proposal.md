# Change: 修复项目分析结果与取消链路

## Why

DeepSeek 网页已经返回 `final` JSON 时，项目 Agent 仍可能只显示“模型没有生成最终回答”；同时仓库下载、解压、索引阶段没有绑定取消信号，用户无法及时停止长任务。

## What Changes

- 从 Agent 最终消息兜底收集文本，并保留网页传输层的真实错误。
- 使用同一个 `AbortController` 覆盖项目导入、解压、索引、保存和 Agent 分析。
- 项目忙碌期间始终显示停止按钮；停止后不显示错误，也不继续进入后续阶段。
- 长时间同步扫描分批让出主线程，避免侧栏失去响应。

## Out of Scope

- 私有 GitHub 仓库认证。
- 改变 DeepSeek 网页 JSON 工具协议。

## Acceptance

- DeepSeek 返回合法 `final` action 后，侧栏显示 Markdown 回答。
- 网页传输失败时显示具体错误，而不是通用“没有生成最终回答”。
- 下载、解压、索引或 Agent 执行任一阶段均可点击停止并快速回到空闲状态。
- 现有论文分析与项目工具调用测试继续通过。
