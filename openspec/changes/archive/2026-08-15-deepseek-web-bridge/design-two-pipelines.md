## PDF 线

入口：当前页是 PDF / 粘贴 PDF 链接 / 「上传 PDF」/ **网页模式解读当前页时找到的下载入口**。

| 模型通路 | 策略 |
|---|---|
| DeepSeek 网页 | **下载 PDF 字节 → 上传附件** + 短提示（不抽正文粘贴） |
| API | pdf.js 抽文本 → 智能摘取 |

网页模式「解读当前页面」会先找页面上的「下载 PDF」(含 arXiv abs→pdf)，找到就走 PDF 线。

## HTML 线

入口：找不到 PDF 下载时的网页正文、粘贴任意文字。

| 模型通路 | 策略 |
|---|---|
| DeepSeek 网页 / API | Readability / 粘贴文本 → 智能摘取 |

## 会话策略（设置）

- **单轮**：每次回答新开 DeepSeek 会话
- **多轮**：同一篇材料同一会话追问（不再重复上传 PDF）
