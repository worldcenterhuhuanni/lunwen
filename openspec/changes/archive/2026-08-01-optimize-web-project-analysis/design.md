# Design

## 双管线

- API Provider：保持 Pi Agent、原生 function calling 和按需工具取证。
- DeepSeek 网页 + GitHub：不模拟工具循环。本地确定上下文后，只发送一次“证据包 + 分析要求”，模型直接返回最终 Markdown。
- DeepSeek 网页 + 本地工作区：暂时保留 Agent，以维持候选 patch、diff 审阅和确认写回语义。

## 上下文包

1. 从 IndexedDB 读取完整安全索引。
2. 生成受长度限制的仓库地图，保留所有路径的整体结构视图。
3. 对文件评分：
   - 项目清单、README、构建配置、入口文件优先；
   - 默认分析提高核心源码和测试权重；
   - 追问根据路径与内容关键词提高相关文件权重；
   - 锁文件、快照和低信息文档降权。
4. 在 `maxContextChars` 内依次加入带路径边界的源码；大文件按相关行窗口或头尾片段摘取。
5. 输出已包含与省略文件统计，禁止模型把“未进入本次上下文”等同于“不存在”。

## 网页输出

要求 DeepSeek 将 Markdown 原文放入 `markdown` 代码围栏，避免 DOM Markdown 渲染丢失标题、反引号和代码格式。桥接层兼容有无围栏的返回。

## 超时

外层桥接维护“最后收到内容时间”和十分钟硬上限；只有连续三分钟没有新内容才超时。页面监听同步采用十分钟硬上限，并继续根据生成按钮和文本稳定状态提前完成。
