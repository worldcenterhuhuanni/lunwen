# 大窗口阅读与设置

## Why

设置页目前走 Chrome 狭小的 `options_ui` 弹层，模板工作台空间不足；论文放大阅读仍困在侧栏内，长内容滚动后操作图标消失，无法随时打开。

## What

- 设置与论文放大阅读统一为可控尺寸的居中扩展窗口（`windows.create` popup）
- 默认关闭「独立大窗口」：放大阅读留在侧栏遮罩；开启后才跳独立大窗
- 新增「解读时跳转 DeepSeek」：默认开启；关闭后网页桥接不抢标签焦点
- 放大内容经 `storage.session` 传递，独立 `reader` 页渲染
- 结果卡片放大按钮改为卡片内 sticky，hover 显示且滚动时可点
- 设置页 `open_in_tab=true`，并从侧栏打开大尺寸设置窗口（大窗模式）

## Not

- 不把 Markdown 注入当前网页 DOM
- 不改变论文提取、模型调用与模板逻辑
- 不引入远程字体或新 UI 框架

## 验收

1. 侧栏点设置 / 管理会打开约 1100×860 的居中窗口，内容可读可编辑
2. 完整解读 hover 显示放大图标；长文滚动时图标仍可点击
3. 放大阅读在独立大窗口打开，不占侧栏遮罩
4. 阅读数据缺失时给出可操作提示；关闭后清理临时会话数据
5. Escape / 关闭按钮可退出阅读窗口
