# 提示词模板工作台

## Why

PDF 与 HTML 解读提示词目前硬编码，用户无法按阅读目标切换，也无法持续优化。需要本地模板库，让专业分析框架可配置、可编辑、可复用。

## What

- 提供专业内置模板和 PDF/HTML 独立默认模板
- 模板保存在浏览器本地，支持创建、复制、编辑、删除和运行时选择
- 支持变量渲染、即时预览和 AI 生成模板草稿
- DeepSeek 网页 PDF 附件模式也完整执行 system/user 模板

## Not

- 不提供云端模板市场或账号同步
- 不执行任意脚本，仅替换固定白名单变量
- AI 生成结果不自动保存，必须由用户确认

## 验收

1. 老版本配置升级后仍可直接解读
2. PDF 与 HTML 可配置不同默认模板，侧栏可临时切换
3. 模板可在本地增删改选并即时预览
4. 用户可描述目标，由当前模型生成可编辑模板草稿
5. PDF 上传、PDF 文本和 HTML 三条通路均按所选模板执行
